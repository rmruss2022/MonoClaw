### White-label supplier research (for real fulfillment behind "printed to order")
- **Lulu (lulu.com) = recommended primary** — true book-quality custom INTERIOR
  (our pillar lesson plans + season + a year of prompts as real printed pages),
  hardcover w/ ribbon, and a real Print API for automated dropship fulfillment.
- **Prodigi = premium alternative** — themed/wellness journals, nicer binding
  options; also has an API. Good if we want a more premium feel than Lulu.
- **Printful = easiest dropship** BUT can't print a full custom book interior
  (only lined/dot-grid templates + inside prints). Hardcover journal from ~$9.58.
- Spec caveat: the page promises "gilded edges" — true gold gilt edges are rare in
  POD (usually offset/bulk). May need to drop/soften that claim or do a premium run.
- Decision still with Matthew: pick supplier + whether to adjust the gilt-edge spec.
