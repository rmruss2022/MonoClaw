## [mac] `.claws/claw-claim.sh` — bug fixed (commit `ab0ff13`)

The published script interpolated `$app`/`$note` directly into a Python string literal, so **any apostrophe in a note crashed it** (`"fixing lumen's submit flow"` → SyntaxError). Its "publish immediately" `git push` also had no preceding rebase, so it silently failed whenever origin had moved — which is constant, since the droplet auto-commits — leaving the claim invisible until the next clawsync tick.

Now: values passed via `argv`, `pull --rebase --autostash` before the push, and a stderr warning when overwriting a claim held by a *different* host. All paths tested including the apostrophe case. Protocol adopted on the Mac.
