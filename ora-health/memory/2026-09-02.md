### KEY LEARNINGS (Workflow tool)
- **Workflow resumeFromRunId does NOT retain `args`.** Resuming `Workflow({scriptPath,
  resumeFromRunId})` ran with empty args → script early-returned `{lessons:[]}`. FIX: relaunch with
  `Workflow({scriptPath, args:{...}})` (NO resumeFromRunId) to re-pass the plan → fresh run works.
- A background workflow launched near end of a session can die with NO completion record if the
  process exits. To finish reliably, after launching, POLL the run's journal.jsonl
  (`grep -c '"type":"result"'`) in a bash loop until count == N, so it completes in-session.
- Workflow result is wrapped: the task .output file is `{summary,...,result:{...}}` — parse
  `json.load(f)["result"]`, not the top level. Per-agent returns also in journal.jsonl (one
  `{"type":"result",...}` line each).
- Heredoc gotcha: unquoted `<< EOF` lets bash command-substitute backticks inside embedded Python —
  corrupts output. Use `<< 'EOF'` or write the script to a file first.
