# integrations — compatible hardware

open-home works with devices that speak open protocols, so you truly own them. This is
the vetted compatibility list (grows over time). The rule of thumb: **if it needs a
vendor cloud to work on your LAN, it doesn't belong here.**

- [`cameras/`](./cameras) — ONVIF / RTSP cameras
- [`locks/`](./locks) — Matter / Z-Wave smart locks
- [`lighting/`](./lighting) — Matter / Zigbee bulbs, switches, strips

Each folder lists known-good models, setup notes, and gotchas. Contributions welcome —
see [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
